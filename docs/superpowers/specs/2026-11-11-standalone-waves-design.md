# Самостоятельные волны

## Цель и согласованное поведение
Добавить `/towers wave <type>` для запуска серии волн без задания и калибровки. Право — `towers.admin`, запуск — только игроком. Tab предлагает актуальные ID из `wave-types`.

Рифт создаётся в текущем чанке игрока. После открытия запускается серия выбранного типа с обычными настройками мобов, интервалов и лута. Задания и их прогресс не меняются. Одновременный запуск поверх активных волн игрока запрещён. `/towers test cancel` отменяет самостоятельный запуск.

Дополнительно исправить Tab для `/towers test loot <type>`: сейчас обработчик ошибочно ожидает четвёртый аргумент вместо третьего.

## Подходы
- Выбран отдельный запуск без задания: временные данные отделены от сохранённого прогресса, механика волн переиспользуется.
- Скрытое задание отклонено: оно затрагивает прогресс и противоречит требованию работы без задания.
- Отдельный дублирующий движок волн не нужен: существующие механизмы рифта, мобов и лута уже реализованы.

## Ограничения и границы
Paper API 1.21+, Java 21, Maven. Новые сообщения — Adventure Component/MiniMessage. В долгоживущих коллекциях хранить UUID, не Player/Entity. Вода и занятые чанки не должны приводить к наложению или зависанию запуска. Временный запуск очищается при выходе игрока и выключении плагина; сохранение самостоятельных волн между перезапусками не входит в задачу (решение реализации).

Проверки: неизвестный тип и повторный запуск не создают сущностей; выбранный тип используется для всех волн и лута; завершение и отмена не вызывают изменение заданий; Tab фильтрует ID по префиксу и учитывает права.
